RECOMMENDED DOMAIN SETUP
Do NOT run both domains as separate copies of the website.
Keep northcornwallairporttransfers.co.uk as the canonical/primary domain.
301 redirect northcornwalltransfers.co.uk to:
https://northcornwallairporttransfers.co.uk/$1

CLOUDFLARE
1. Add northcornwalltransfers.co.uk to Cloudflare if it is not already there.
2. Make sure its DNS is active on Cloudflare.
3. Go to Rules > Redirect Rules.
4. Create a Single Redirect.
5. Match hostname:
   northcornwalltransfers.co.uk
6. Redirect dynamically to the same path on:
   https://northcornwallairporttransfers.co.uk
7. Use status code 301.
8. Preserve query strings.

This prevents Google treating the two domains as duplicate websites.
